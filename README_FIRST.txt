================================================================================
   🐛 TROUBLESHOOTING
================================================================================

Issue: Images won't upload
Fix: Restart server (Ctrl+C, then npm run dev)

Issue: Port 3000 in use
Fix: npx kill-port 3000

Issue: Module errors
Fix: rm -rf node_modules && npm install

Issue: MongoDB connection
Fix: Check .env.local configuration

More help: Read SETUP_INSTRUCTIONS.md (Troubleshooting section)
