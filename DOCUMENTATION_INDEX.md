## 💡 Quick Reference

### Common Commands:
```bash
npm install          # Install dependencies
npm run seed        # Add sample data
npm run dev         # Start development
npm run build       # Build for production
npm run start       # Start production server
```

### Important URLs:
```
Homepage:        http://localhost:3000
Admin Panel:     http://localhost:3000/admin
Add Product:     http://localhost:3000/admin/products/new
Products List:   http://localhost:3000/admin/products
Categories:      http://localhost:3000/admin/categories
Orders:          http://localhost:3000/admin/orders
Reviews:         http://localhost:3000/admin/reviews
```

### Important Paths:
```
Images:          src/components/admin/ImageUpload.tsx
Products:        src/app/admin/products/
Upload API:      src/app/api/upload/route.ts
Database:        src/models/
Configuration:   .env.local
```
